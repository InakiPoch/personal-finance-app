## Gaps and weak points

- No primary source covers "generate a stripped release branch from a full dev branch" as a named practice. Sources 1, 3, 9, 10 supply the building blocks only.
- Source 13 predates .NET 10. Image tag names (`10.0-noble-chiseled-extra`) come from internal memory (#18) and must be confirmed against the Docker Hub/MCR tag list when implementing.
- Sources 14, 16, 17 are directional (grade B/C) and are used only for context, never as the sole basis of a recommendation.
